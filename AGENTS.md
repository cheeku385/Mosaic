# Repository Rules and Guidelines

## File Preservation Rules
- **Do NOT overwrite or delete `README.md`**: The `README.md` file is maintained manually by the project owner with details, credits, and links. Never modify, overwrite, regenerate, or delete `README.md` unless explicitly requested by the user.
- **Targeted File Modifications**: Only modify files directly relevant to the feature or bug fix requested by the user (such as components, pages, or config files).
