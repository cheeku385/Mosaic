<h1 align="center">🗄️ Mosaic</h1>
<p align="center"><i>Your files, backed up on-chain. No servers, no single point of failure.</i></p>

---

## The Problem

Cloud backups live on someone else's server. If that company shuts down, 
gets hacked, or changes its terms — your files are at risk. Mosaic stores 
your documents on Shelby's decentralized network instead, where no single 
company controls access to your data.

## How It Works

1. Connect your Aptos wallet (Petra)
2. Upload a document — it's stored via Shelby Protocol's decentralized 
   storage network
3. Every upload is a real, signed on-chain transaction — verifiable proof 
   it happened
4. Choose Public or Private visibility for each file
5. Access your backups anytime from your dashboard
